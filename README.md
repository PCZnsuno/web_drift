# 纸舟 Windows 本地预览版 0.5

将压缩包完整解压到一个文件夹，双击 Paperboat.exe（或「启动纸舟.cmd」）。不要单独移动 EXE；不要直接双击 index.html。需要 Windows 和 Microsoft Edge；无需安装 Node.js。启动器未签名。

## 本次改动

- 缩放移到阅读器右下角：精细滑杆、百分比输入，以及圆润的缩放菜单（适合宽度、适合页面、实际大小、常用比例），替换了原生缩放下拉框。
- 移除文字识别（OCR）、导出 Word、导入 Word/PPT 及其界面入口、服务端点和发布依赖，包体明显变小。
- 首页改为「我的文档」，去掉底部宣传语；统一更柔和的圆角、阴影和轻量动效，并保留减少动态效果支持。
- PDF 专用文件图标按最后提供的参考图重做：白色圆润折角文档、薄荷绿描边、绿色 P。

## 保留的功能

阅读与批注、文字标记、页签、批注导出、导出文字、当前页图片、导出 PDF、手写笔记、页面整理、图片转 PDF、四种阅读配色、本机自动保存。

## 数据与备份

导入的 PDF 和批注保存在本机浏览器 IndexedDB 中，不会自动修改原始文件。请及时导出 PDF。清除浏览器数据会删除本机副本。不同浏览器、不同端口的书架相互独立。

手写笔迹与 PDF 分开存储。备份 JSON 恢复时校验原 PDF 指纹与页数，请保留对应原 PDF。带笔记 PDF 是栅格化副本，不再保留搜索文字和交互表单。

## 尚未完成

跨设备同步与移动端尚未实现；页面整理不保证保留目录、内部链接、表单和签名；启动器已支持接收双击文件路径，但完整 Windows 文件关联链路仍需在目标机器上复测。

## 验证状态

缩放控件、移除功能后的入口、示例 PDF 打开与阅读、手写笔记、页面整理会在本机浏览器中实际回归；未验证的项目不会写成已完成。

第三方许可证随各组件保留。纸舟本身不向外上传文档。

## 本机更新：扫描件识别与工具快捷键

- 阅读工具栏新增“识别文字”：本地识别简体中文、英文，支持当前页、指定页码和整份文档，支持取消与结果缓存。
- 识别完成后自动打开“原名-已识别.pdf”新副本，保留扫描图像和已有批注；文字层支持选取、搜索及批注，导出 PDF 可携带文字层。已有文字的页面自动跳过。
- 识别结果可能有错字或排版误差，尤其是手写字、模糊图像和多栏材料。当前识别范围为简体中文和英文。
- 修复选择、橡皮图标前的黑块；工具样式通过本地 CSS 加载。
- 单字母：V 选择、H 拖动、E 橡皮、C 文字批注、M 高亮、T 文字、B 画笔、I 图片。Esc 返回选择；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
- 设置中可查看快捷键并关闭单字母工具切换；输入文字和中文组词期间不切换工具。
- OCR 所需引擎、字体和语言包均随应用打包，首次识别也无需上传文档或下载模型。第三方来源与许可见 ocr/vendor/。
